### 아키텍처 구성 요소
- MySQL(mysql): 이중화를 고려해야함
- 마이그레이터(migrator): 데이터베이스 마이그레이터
- api 서버(api)
- 웹 서버(web); HTML
- 리버스 프록시(nginx-api)
- 리버스 프록시(nginx-web)

### MySQL
- 설정 파일 작성
- 컨테이너 구성 설정
- data volume, secrets, environment 등

### 데이터베이스 마이그레이터
- golang-migrate; go 언어로 구현된 데이터베이스 마이그레이션 도구
- containers/migrator/history 안에 `임의의 번호_임의의 이름.up|down.sql` 생성
- up.sql 파일은 ddl 정의
```shell
# 체크포인트 이후/이전의 모든 OR 숫자만큼 up/down.sql 실행
migrate -path [마이그레이션 sql 디렉터리] -database [데이터베이스 접속 문자열] up|down [숫자]
```


>`.dockerignore` 파일
> 
> COPY . [컨테이너 디렉터리]로 호스트의 디렉터리를 컨테이너에 복사할 때 
> Dockerfile과 같은 디렉터리에 `.dockerignore`를 사용해 COPY 대상이 되는 파일과 디렉터리를 제외
> 
> 와일드카드는 가능하지만 정규 표현식은 불가
